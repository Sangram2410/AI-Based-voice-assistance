# AI Voice Assistant for People with Disabilities

## Introduction

The AI Voice Assistant is a Python-based accessibility project designed to help people who may have difficulty using traditional computer input devices such as keyboards and mice.

The system accepts voice commands and provides spoken responses.

## Objectives

The main objectives of this project are:

1. Provide hands-free computer interaction.
2. Help users with physical disabilities.
3. Reduce dependence on keyboard and mouse.
4. Provide spoken information.
5. Open websites using voice commands.
6. Search the internet using voice.
7. Provide basic computer accessibility features.

## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- Web Browser
- Object-Oriented Programming

## Features

### Voice Input

The user can speak commands through a microphone.

### Text-to-Speech

The assistant responds using synthesized speech.

### Web Navigation

The assistant can open:

- Google
- YouTube
- Gmail
- Wikipedia

### Google Search

The user can say:

"Search Python programming"

The assistant will open Google with the search query.

### Date and Time

The assistant can tell the current date and time.

### Folder Access

The user can open:

- Home folder
- Documents folder

### Help

The user can say:

"Help"

to hear available commands.

## Example Commands
